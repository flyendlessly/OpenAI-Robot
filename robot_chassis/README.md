# 智能 AI 小车底盘子系统 (Robot Chassis Subsystem)

> **定位**：高可靠性移动底盘子系统，提供**“单片机一体化”**与**“双芯片分布式”**双轨架构支持。  
> **核心设计哲学**：**软硬解耦、契约先行、防御性安全设计、硬件资产 100% 复用**。

---

## 1. 架构总览：双轨并行形态 (Dual-Track Architectures)

本底盘系统设计为**“一套硬件底座，两种驱动形态”**，满足从低成本快速验证到高阶多模态智能体的平滑过渡：

```text
               ┌────────────────────────────────────────────────────────┐
               │         公共硬件底座 (Common Physical Base)              │
               │   4WD 动力底盘 + 电机驱动板 (AT8236/TB6612) + 18650 供电   │
               │        (供电与抗干扰规范见: POWER_SUPPLY.md)             │
               └──────────────────────────┬─────────────────────────────┘
                                          │
                   ┌──────────────────────┴──────────────────────┐
                   ▼                                             ▼
  【形态 A：小智 AI 一体化极简模式】            【形态 B：树莓派分布式认知模式】
  - 主控：单片 ESP32-S3 (N16R8)                  - 大脑：树莓派 4B/5 (Linux + Python)
  - 特点：无需树莓派，单芯片全双工语音+控车      - 小脑：ESP32-S3 (FreeRTOS 闭环驱动)
  - 成本：百元内，秒开机，续航长                 - 特点：支持高清视觉追踪、SLAM建图、复杂Agent
  - 核心入口：XIAOZHI_CAR_GUIDE.md               - 核心入口：ARCHITECTURE.md / PROTOCOL.md
```

## 3. 你应该如何选择？

### 🚀 路径 1：立刻上手开跑 -> 选择【形态 A：小智 AI 模式】
* **现状**：手头有 ESP32-S3 + 麦克风喇叭，暂时没有树莓派。
* **步骤**：
  1. 阅读 [POWER_SUPPLY.md](POWER_SUPPLY.md) 了解电池与电机接线；
  2. 照着 [XIAOZHI_CAR_GUIDE.md](XIAOZHI_CAR_GUIDE.md) 将 `xiaozhi_car/` 中的电机代码合入小智源码；
  3. 编译烧录，直接开口说话操控小车。

### 🧠 路径 2：进阶视觉与复杂自主导航 -> 升级到【形态 B：树莓派模式】
* **现状**：后续购入树莓派，需要搭载摄像头人脸追踪、激光雷达建图或运行本地复杂 Agent。
* **步骤**：
  1. 底盘硬件和电池完全不需要更换（100% 沿用）；
  2. 给 ESP32-S3 刷入 [esp32_firmware/](esp32_firmware/) 标准串口固件，作为专注电机与安全的“小脑”；
  3. 树莓派插上 USB 数据线，运行 `my-openai-robot` 作为“大脑”接管全局规划。
