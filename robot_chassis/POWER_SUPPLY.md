# 小车硬件供电方案与接线规范 (Power Supply Guide)

> **核心安全准则**：**电机与逻辑分路供电、单点星型共地、大电容抗瞬态消峰**。
> 电机是强感性负载，启动和堵转时会产生较大瞬态电流和反电动势。合理供电与布线可降低主控（ESP32 / 树莓派）复位风险，但不能替代按电机堵转电流选型，也不能保证主控绝不复位。

---

## 1. 方案全景与选型对比

| 阶段 / 场景 | 推荐电池方案 | 降压/供电方案 | 适用说明 |
| :--- | :--- | :--- | :--- |
| **场景 A：仅 ESP32-S3 (无树莓派)<br>面包板点灯/协议调测** | **无需电池** (电脑 USB 供电) | Type-C 数据线直接直连电脑 | 阶段 1 验证，0 硬件成本，安全方便 |
| **场景 B：仅 ESP32-S3 (无树莓派)<br>带 4WD 动力跑车** | **2S 18650 (7.4V 标称，满电 8.4V)** | 电池经开关后接两块 **DRV8833** 的 VM；另一路降压至 5V 给 ESP32-S3 | 先确认电机额定电压和堵转电流 |
| **场景 C：完整体 (树莓派 + ESP32 + 4WD 电机)** | **3S 动力 18650 (11.1V~12.6V)** | 电机支路单独降压至电机额定电压（不得超过 10.8V）；逻辑支路降压至 5.1V (≥4A) | **3S 不得直连 DRV8833 VM**；降压模块需承受电机启动/堵转电流 |

---

## 2. 当前阶段（只有 ESP32-S3，无树莓派）的电池方案

如果你当前正在准备组装动力底盘，手头暂时没有树莓派，推荐以下两种实施路径：

### 方案 2.1：双电源分别供电方案（推荐用于初次调试）
* **原理**：控制系统与电机分别供电，共地传递控制信号；这不是电气隔离。
* **配置**：
  * **ESP32-S3 供电**：任意普通小充电宝（输出 5V），通过 Type-C 线直接给 ESP32-S3 供电。
  * **4WD 电机供电**：2 节 18650 电池盒（7.4V 标称，满电 8.4V），经开关接两块 DRV8833 模块的 `VM` 引脚。不得将 3S 电池直接接入 DRV8833。
* **接线关键**：
  * **必须共地**：把充电宝出来的 GND（或 ESP32 的 GND 引脚）与 18650 电池盒的负极（GND）**牢固连在一起**。
  * **优点**：分开供电可降低电机瞬态对 ESP32 供电的影响；两路仍通过 GND 共地，并不能保证绝不复位，仍需检查电流、布线和电源质量。

---

### 方案 2.2：单电池组集成方案（优先 2S；使用 3S 时电机支路必须降压）
* **配置**：
  * 电池盒：带保护板的 2S 或 3S 18650 动力电池盒。
  * 5V 降压模块：为 ESP32-S3 供电。若使用 3S 电池，还需另配可承受电机启动/堵转电流的电机支路降压模块。
* **接线图**：
```text
           [ 18650 电池盒 (2S 7.4V 或 3S 11.1V) ]
                            │
                      [ 船型开关 ]
                            │
                     ┌────────────┴────────────────────┐
                     │                                 │
                   [电机动力支路]                     [DC-DC 降压模块]
                   2S: 电池直供 VM                    (输出精准调至 5.0V)
                   3S: 电机专用降压                         │
                   输出 ≤ 10.8V                              ▼
                     ▼                          [ ESP32-S3 ]
                   [两块 DRV8833]                    5V / VIN 供电引脚
                     │                                 │
                     └──────────────┬──────────────────┘
                        ▼
                      【 共同接地 (GND) 】
```

DRV8833 的 VM 推荐工作范围为 2.7V~10.8V。若使用 3S 电池，电机支路必须增加独立的大电流降压模块，输出设为电机额定电压且不超过 10.8V；3S 满电 12.6V 不可直连。

> 使用 3S 时，电机降压模块和 5V 逻辑降压模块是两条独立支路；不可把 3S 电池或 5V 逻辑电源误接到 DRV8833 的 VM。

## 3. 完整体方案（树莓派 + ESP32-S3 + 4WD 电机）

### 3.1 为什么完整体必须选 3S 18650 (11.1V~12.6V)？
1. **压差安全边际**：
   - 树莓派 4B/5 满载功率达 15W~25W（5V / 3A~5A）。当电池接近放电截止电压时，如果用 2S 电池，电压会跌落到 6.4V 左右，压差极小，电机启动时引发的微秒级压降很容易让树莓派报“Under-voltage”欠压关机。
   - 3S 电池在截止状态仍有 9.6V，到 5V 始终保留有 >4V 的充沛压差，降压芯片可以维持极高纹波抑制比和输出稳定性。
2. **电机性能匹配**：
  - DRV8833 的 VM 推荐范围为 2.7V~10.8V。若电机额定电压为 12V，不应直接由 DRV8833 驱动；应改用额定电压、电流更合适的驱动器。

### 3.2 供电拓扑架构

```text
       [ 3S 18650 动力电池组 (9.6V ~ 12.6V) ]
                   │
                   ▼
             [ 主船型开关 ]
                   │
         ┌─────────┴───────────────────────┐
         │                                 │
       (电机动力支路：高电流降压)          (数字逻辑支路：5.1V 降压)
       (输出=电机额定电压且 ≤10.8V)        (输入 9.6V~12.6V，输出 4A~5A)
         │                                 │
         ▼                                 ├────────────────────────┐
         [ 两块 DRV8833 ]                       ▼                        ▼
       (VM 不得超过 10.8V)             [ 树莓派 4B / 5 ]           [ ESP32-S3 ]
         │                         5V / USB-C 供电            由树莓派 USB 直供
         │                                                   (或接 5V 稳压引脚)
         └─────────────────┬─────────────────────────────────────┘
               ▼
              【 全系统唯一星型共地点 】
               (Star Ground / 负极汇聚)
```

## 4. 详细引脚与线缆对照表

### 4.1 DC-DC 降压模块输出接线
* 降压模块输出电位必须用万用表调整为 **5.1V ~ 5.2V**（树莓派官方推荐在负载线上预留 0.1V 线损补偿）：
  * `OUT+ (5.1V)` -> 接树莓派 40Pin GPIO 的 **Pin 2 (5V)** 或 **Pin 4 (5V)**（或剪一根粗 Type-C 线接主板电源口）。
  * `OUT- (GND)` -> 接树莓派 40Pin GPIO 的 **Pin 6 (GND)**。

### 4.2 ESP32-S3 的两种接线选择
* **方式 1（极简推荐）**：ESP32-S3 直接用一根短 USB 数据线插在树莓派的 USB 3.0/2.0 口上。
  * **好处**：一条线同时搞定供电和串口通信（`/dev/ttyUSB0` 或 `/dev/ttyACM0`），连线最清爽。
* **方式 2**：从降压模块引出 5V 接 ESP32-S3 的 `5V/VIN`，通信走 TX/RX 硬件串口。

### 4.3 两块 DRV8833 接线（每个电机使用独立 H 桥）

每块 DRV8833 有两路 H 桥；两块模块共提供四路，分别驱动四个电机。左右同侧的两路输入使用相同方向信号，但各电机接独立输出，**不要把两个 H 桥的输出并联**。

| 模块/引脚 | 接线 | 说明 |
| :--- | :--- | :--- |
| 左侧模块 `VM` | 2S 电池正极（经总开关）；3S 时接电机降压输出 | 电压匹配电机，且不得超过 10.8V |
| 右侧模块 `VM` | 同左侧模块 `VM` | 两模块共用电机电源支路 |
| 两模块 `GND` | 电池负极汇流点 | 并与 ESP32-S3 GND 共地 |
| 左侧 `AIN1` 与 `BIN1` | 并接 ESP32-S3 GPIO 1 | 左前、左后电机正向控制 |
| 左侧 `AIN2` 与 `BIN2` | 并接 ESP32-S3 GPIO 2 | 左前、左后电机反向控制 |
| 左侧 `AOUT1/AOUT2` | 左前电机两端 | 若方向相反，对调该电机两根线 |
| 左侧 `BOUT1/BOUT2` | 左后电机两端 | 独立 H 桥输出 |
| 右侧 `AIN1` 与 `BIN1` | 并接 ESP32-S3 GPIO 41 | 右前、右后电机正向控制 |
| 右侧 `AIN2` 与 `BIN2` | 并接 ESP32-S3 GPIO 42 | 右前、右后电机反向控制 |
| 右侧 `AOUT1/AOUT2` | 右前电机两端 | 若方向相反，对调该电机两根线 |
| 右侧 `BOUT1/BOUT2` | 右后电机两端 | 独立 H 桥输出 |
| 两模块 `nSLEEP` / `SLEEP`（若引出） | 接 ESP32-S3 3.3V | 拉高使能；确认板载上拉情况，不可悬空 |

DRV8833 芯片不需要单独的逻辑 `VCC` 供电；若模块板另有 `VCC` 标记，按该模块原理图确认后再接，勿将电机电压接到 ESP32-S3。上电前需核对每个电机的堵转电流是否在模块散热条件允许的范围内，模块板标称连续电流可能低于芯片规格。

## 5. 硬件抗干扰与工程铁律 (Three Iron Laws)

### 铁律 1：单点“星型共地”（Star Grounding）
- **绝不允许**把驱动板大电流电机的大负极接线串接经过单片机/树莓派排针上的细地线。
- **必须做到**：电机驱动板的 GND、DC-DC 模块的 IN-、OUT- 以及主控板的 GND，全部独立拉线汇聚到**电池负极汇流排/端子**上。

### 铁律 2：电解电容滤波消峰
- 电机在正反转与急刹瞬间会向总线反冲很高的电感毛刺。
- 在每块 DRV8833 的 `VM` 与 `GND` 引脚间，紧贴引脚并联一个 **470μF ~ 1000μF / 25V 电解电容**。
- 在 DC-DC 降压模块给树莓派输出的 5V 端，并联一个 **220μF 固态电容**，平抑高频纹波。

### 铁律 3：配置总电源物理开关
- 电池正极引出线上串联机械总开关；开关、导线和电池保护板的额定电流应高于实测/估算的最大总电流（需计入四个电机启动或堵转电流），不要仅按固定的 5A 选型。
- 一旦发生代码异常、底盘撞墙失控或短路，能够以毫秒级速度一键物理断电。
