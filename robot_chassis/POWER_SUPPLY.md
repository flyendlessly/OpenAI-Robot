# 小车硬件供电方案与接线规范 (Power Supply Guide)

> **核心安全准则**：**强弱电隔离、单点星型共地、大电容抗瞬态消峰**。  
> 电机是强感性负载，启动和堵转时会产生巨大瞬态电流和反电动势。本方案保障在电机猛烈启停时，主控（ESP32 / 树莓派）绝不复位掉电。

---

## 1. 方案全景与选型对比

| 阶段 / 场景 | 推荐电池方案 | 降压/供电方案 | 适用说明 |
| :--- | :--- | :--- | :--- |
| **场景 A：仅 ESP32-S3 (无树莓派)<br>面包板点灯/协议调测** | **无需电池** (电脑 USB 供电) | Type-C 数据线直接直连电脑 | 阶段 1 验证，0 硬件成本，安全方便 |
| **场景 B：仅 ESP32-S3 (无树莓派)<br>带 4WD 动力跑车** | **2S 18650 (7.4V~8.4V)**<br>或 **3S 18650 (11.1V~12.6V)** | **双路隔离** 或 **加 Mini360 降压到 5V** | 动力充沛，小车底盘可独立落地跑动 |
| **场景 C：完整体 (树莓派 + ESP32 + 4WD 电机)** | **3S 动力 18650 (11.1V~12.6V)** | **高效率同步整流 DC-DC 降压至 5.1V (≥4A)** | 专供树莓派吃满性能，无惧低电压告警 |

## 2. 当前阶段（只有 ESP32-S3，无树莓派）的电池方案

如果你当前正在准备组装动力底盘，手头暂时没有树莓派，推荐以下两种实施路径：

### 方案 2.1：双电源隔离方案（新手极力推荐，零烧板风险）
* **原理**：将控制系统与动力驱动物理隔离。
* **配置**：
  * **ESP32-S3 供电**：任意普通小充电宝（输出 5V），通过 Type-C 线直接给 ESP32-S3 供电。
  * **4WD 电机供电**：2 节 18650 电池盒（7.4V 标称），接电机驱动板（TB6612 / AT8236 / L298N）的 `VM` 引脚。
* **接线关键**：
  * **必须共地**：把充电宝出来的 GND（或 ESP32 的 GND 引脚）与 18650 电池盒的负极（GND）**牢固连在一起**。
  * **优点**：电机不管怎么堵转、反转，绝不可能把高压串入 ESP32，ESP32 供电极其纯净，绝对不重启。

---

### 方案 2.2：单电池组集成方案（2S 18650 7.4V 或 3S 18650 11.1V）
* **配置**：
  * 电池盒：带保护板的 2S 或 3S 18650 动力电池盒。
  * 降压模块：一块微型 DC-DC 降压板（如 **Mini360** 或 **MP1584EN**，成本仅 2~3 元）。
* **接线图**：
```text
           [ 18650 电池盒 (2S 7.4V 或 3S 11.1V) ]
                            │
                      [ 船型开关 ]
                            │
               ┌────────────┴─────────────┐
               │                          │
      (12V/7.4V 直供)                     │
               │                          ▼
               │                [ DC-DC 降压模块 ]
               │                (输出精准调至 5.0V)
               ▼                          │
        [ 电机驱动板 ]                     ▼
        VM (电机动力源)              [ ESP32-S3 ]
               │                     5V / VIN 供电引脚
               │                          │
               └────────────┬─────────────┘
                            ▼
                    【 共同接地 (GND) 】
```

> **一步到位建议**：如果你之后肯定会上树莓派，现在直接买 **3S 18650 电池盒 + 12.6V 充电器**。现在只接 ESP32-S3 跑，未来加树莓派时电池部分完全不需要重新换买。

## 3. 完整体方案（树莓派 + ESP32-S3 + 4WD 电机）

### 3.1 为什么完整体必须选 3S 18650 (11.1V~12.6V)？
1. **压差安全边际**：
   - 树莓派 4B/5 满载功率达 15W~25W（5V / 3A~5A）。当电池接近放电截止电压时，如果用 2S 电池，电压会跌落到 6.4V 左右，压差极小，电机启动时引发的微秒级压降很容易让树莓派报“Under-voltage”欠压关机。
   - 3S 电池在截止状态仍有 9.6V，到 5V 始终保留有 >4V 的充沛压差，降压芯片可以维持极高纹波抑制比和输出稳定性。
2. **电机性能匹配**：
   - 12V 是市面上大部分减速电机、编码器电机的标准额定工作电压。

### 3.2 供电拓扑架构

```text
       [ 3S 18650 动力电池组 (9.6V ~ 12.6V) ]
                   │
                   ▼
             [ 主船型开关 ]
                   │
         ┌─────────┴───────────────────────┐
         │                                 │
     (动力大电流支路)                (数字逻辑弱电支路)
         │                                 │
         │ (12V 直供)                      ▼
         │                     [ 同步整流 DC-DC 降压模块 ]
         │                     (输入 12V -> 输出精准 5.1V / 4A~5A)
         │                     (推荐: TPS5430 / XL4015 / Mini560 5A)
         │                                 │
         ▼                                 ├────────────────────────┐
   [ 电机驱动板 ]                          ▼                        ▼
 (TB6612 / AT8236)                [ 树莓派 4B / 5 ]           [ ESP32-S3 ]
  VM (电机高压引脚)                5V / USB-C 供电            由树莓派 USB 直供
         │                                 │                 (或接 5V 稳压引脚)
         │                                 │                        │
         └─────────────────┬───────────────┴────────────────────────┘
                           ▼
                    【 全系统唯一星型共地点 】
                     (Star Ground / 负极汇聚)
```

## 4. 详细引脚与线缆对照表

### 4.1 DC-DC 降压模块输出接线
* 降压模块输出电位必须用万用表调整为 **5.1V ~ 5.2V**（树莓派官方推荐在负载线上预留 0.1V 线损补偿）：
  * `OUT+ (5.1V)` -> 接树莓派 40Pin GPIO 的 **Pin 2 (5V)** 或 **Pin 4 (5V)**（或剪一根粗 Type-C 线接主板电源口）。
  * `OUT- (GND)` -> 接树莓派 40Pin GPIO 的 **Pin 6 (GND)**。

### 4.2 ESP32-S3 的两种接线选择
* **方式 1（极简推荐）**：ESP32-S3 直接用一根短 USB 数据线插在树莓派的 USB 3.0/2.0 口上。
  * **好处**：一条线同时搞定供电和串口通信（`/dev/ttyUSB0` 或 `/dev/ttyACM0`），连线最清爽。
* **方式 2**：从降压模块引出 5V 接 ESP32-S3 的 `5V/VIN`，通信走 TX/RX 硬件串口。

### 4.3 4WD 电机驱动板接线（以常见驱动模块为例）
* `VM` (电机驱动电源)：接 3S 电池正极经过开关后的 12V。
* `VCC` (芯片逻辑电源)：接 3.3V 或 5V（可从 ESP32-S3 引出）。
* `GND`：汇聚到电源总负极。
* 电机通道并联：
  * 左前电机 + 左后电机并联 -> 接驱动板 `OUT1 & OUT2`。
  * 右前电机 + 右后电机并联 -> 接驱动板 `OUT3 & OUT4`。

## 5. 硬件抗干扰与工程铁律 (Three Iron Laws)

### 铁律 1：单点“星型共地”（Star Grounding）
- **绝不允许**把驱动板大电流电机的大负极接线串接经过单片机/树莓派排针上的细地线。
- **必须做到**：电机驱动板的 GND、DC-DC 模块的 IN-、OUT- 以及主控板的 GND，全部独立拉线汇聚到**电池负极汇流排/端子**上。

### 铁律 2：电解电容滤波消峰
- 电机在正反转与急刹瞬间会向总线反冲很高的电感毛刺。
- 在电机驱动板的 `VM` 与 `GND` 引脚间，紧贴引脚并联一个 **470μF ~ 1000μF / 25V 电解电容**。
- 在 DC-DC 降压模块给树莓派输出的 5V 端，并联一个 **220μF 固态电容**，平抑高频纹波。

### 铁律 3：配置总电源物理开关
- 必须在电池正极引出线上串联一个额定电流 ≥ 5A 的**船型机械开关**。
- 一旦发生代码异常、底盘撞墙失控或短路，能够以毫秒级速度一键物理断电。
