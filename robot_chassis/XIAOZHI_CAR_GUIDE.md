## 1. 为什么要修改/添加代码？

* **官方现成固件**：只包含麦克风录音、音频播放、Wi-Fi 连接和小智云端对话协议，它并不知道你的开发板连了轮子，更没有驱动电机的代码。
* **我们新增的代码**：
  * `motor_controller.c/.h`：底盘电机驱动，负责输出电平控制左右轮，并在设定时间（如 1 秒）后硬件级自动断电刹车。
  * `chassis_tool.cc`：给云端大模型暴露的“技能声明”（Tool Call）。大模型理解人类意图后（如“向前开一点”），下发动作命令并触发电机。

## 2. 硬件引脚接线对照表

> ⚠️ **避坑防冲突**：ESP32-S3 (N16R8) 的 `GPIO 35~37` 被片外 PSRAM 占用，音频 I2S 占用了一批引脚。请严格按照以下推荐的空闲 GPIO 接线：

| ESP32-S3 开发板引脚 | 电机驱动板 (AT8236 / TB6612) | 控制对象 | 说明 |
| :--- | :--- | :--- | :--- |
| **GPIO 1** | `IN1` (或 AIN1) | 左侧两电机正转 | 高电平前进 |
| **GPIO 2** | `IN2` (或 AIN2) | 左侧两电机反转 | 高电平后退 |
| **GPIO 41** | `IN3` (或 BIN1) | 右侧两电机正转 | 高电平前进 |
| **GPIO 42** | `IN4` (或 BIN2) | 右侧两电机反转 | 高电平后退 |
| **GND** | `GND` | 全系统共地 | **极其重要！必须共地** |

* **供电接线**（详见 [POWER_SUPPLY.md](POWER_SUPPLY.md)）：
  * 驱动板 `VM`（动力源）：直连 18650 电池组（7.4V 或 12V）。
  * ESP32 供电：通过 Mini360 降压到 5.0V 后接开发板 `5V/VIN` 引脚（或插电脑 Type-C 调测）。

## 3. 三步将小车代码植入小智源码

代码文件已经为你存放在本工程的 `robot_chassis/xiaozhi_car/` 目录中：
- `motor_controller.h`
- `motor_controller.c`
- `chassis_tool.cc`

### 步骤 3.1：拷贝代码到小智工程
打开你下载的 `xiaozhi-esp32` 源码工程目录，将上述 3 个文件复制到小智工程的 `main/` 目录下（或者 `main/tools/` 目录下）。

### 步骤 3.2：将新增源码加入编译列表 (`main/CMakeLists.txt`)
打开小智源码中的 `main/CMakeLists.txt`，在 `SRCS` 列表中加上这几个新文件名。例如：

```cmake
idf_component_register(
    SRCS 
        "application.cc"
        "main.cc"
        # ... 原有的其它源码 ...
        "motor_controller.c"   # <--- 添加这行
        "chassis_tool.cc"       # <--- 添加这行
    INCLUDE_DIRS "."
)
```

### 步骤 3.3：在小智系统启动时初始化电机
打开小智的主入口文件（通常为 `main/application.cc` 或 `main/main.cc`）：
1. 在文件顶部引入头文件：
   ```c
   #include "motor_controller.h"
   ```
2. 在 `app_main()` 或 `Application::Start()` 初始化流程中加入一行：
   ```c
   motor_init(); // 初始化电机 GPIO 与安全防撞定时器
   ```
3. 在小智处理 Tool / MCP 调用的地方（搜索 `OnToolCall` 或 `tools`），将 `control_chassis` 工具的执行挂钩到 `execute_chassis_tool` 即可。

## 4. VS Code + ESP-IDF 编译与烧录全流程

### 步骤 4.1：选择芯片型号
在 VS Code 底部状态栏，确认芯片目标为 **`[ESP32-S3]`**。如果不是，按快捷键 `F1` 输入：
```text
ESP-IDF: Set Espressif Device Target -> 选择 esp32s3
```

### 步骤 4.2：执行编译 (Build)
* 点击 VS Code 底部状态栏的 **圆柱形小图标 (Build Project)**；
* 或者打开集成终端 (`Ctrl + \``) 执行：
  ```bash
  idf.py build
  ```
* 首次编译需要 3~5 分钟，终端提示 `Project build complete` 即为成功。

### 步骤 4.3：烧录与监控日志 (Flash & Monitor)
* 用 USB 数据线将 ESP32-S3 连上电脑，在底部状态栏选准对应的 `COM` 口；
* 点击底部状态栏的 **火焰/闪电图标**（或终端运行 `idf.py -p COMx flash monitor`）；
* 终端会自动刷入固件，并开始打印小智的开机 Wi-Fi 与音频日志。

## 5. 语音交互测试与提示词配置

烧录完成后，配网开机，即可开始体验自然语言控车：

### 5.1 基础动作测试
* **“小智，往前开一米” / “向前走两步”**
  * 大模型调用 `action: forward, duration_ms: 1500`
  * 小车四个轮子正转 1.5 秒后自动停下，小智语音回复：“好的主人，小车向前开动啦！”
* **“向左转一点”**
  * 大模型调用 `action: turn_left, duration_ms: 500`
  * 左轮反转、右轮正转，原地灵巧左转。
* **“给我跳个舞庆祝一下！”**
  * 大模型调用 `action: dance`
  * 小车原地左右有节奏摆动，犹如摇尾巴的小狗。

### 5.2 提示词建议（在小智后台设定）
为了让大模型更主动地利用车身姿态表达情绪，可在小智角色人设提示词中加入一段：
```text
你是一只搭载了 4WD 轮式底盘的机械萌宠小车。
你拥有移动和跳舞的身体技能 (control_chassis)。
当主人夸奖你、让你跳舞、或者让你移动时，请积极调用底盘动作来表达你的情感与执行力！
```

## 6. 常见问题排查 (Troubleshooting)

1. **为什么小车只转一边 / 往反方向跑？**
   - 直流电机接线具有极性：如果前进时发现左边往前转、右边往后转，只需将右电机的两根接线对调一下即可。
2. **说话时小车一启动，ESP32 就重启或断网？**
   - 典型供电问题：电机启动瞬间瞬态电流过大造成欠压复位。
   - 解决办法：严格按照 [POWER_SUPPLY.md](POWER_SUPPLY.md) 实行**单点星型共地**，并在电机输入端并联 **1000μF 电解电容**。
3. **大模型回复“我往前走啦”，但轮子不动？**
   - 检查 GPIO 对应关系（GPIO 1, 2, 41, 42）。
   - 查看串口监控日志，确认是否输出了 `[MotorController] 底盘动作开始...` 日志；若无日志，说明 Tool 回调未挂接成功。
